<mutation-observer>

A custom element that offers a declarative interface to the MutationObserver API.

Source code & documentation

Examples

Try the interactive examples below to observe DOM mutations. Each example displays the latest observed change. Open your browser's developer console to inspect the full mutation-observer-change events and their mutation records.

Attribute changes

Mark the task as completed or incomplete to observe changes to its class attribute, including the previous value.

Pending
Last mutation No mutations observed yet.
Code sample 
<mutation-observer attr="class" attr-old-value>
  <div class="task">
    <label>
      <input type="checkbox" id="taskCheckbox">
      Review pull request
    </label>
    <span id="taskStatus">Pending</span>
  </div>
</mutation-observer>

<script>
  const mutationObserverEl = document.querySelector('mutation-observer');
  const checkbox = document.getElementById('taskCheckbox');
  const taskItem = mutationObserverEl.querySelector('.task');
  const taskStatus = document.getElementById('taskStatus');

  checkbox.addEventListener('change', () => {
    taskItem.classList.toggle('completed', checkbox.checked);
    taskStatus.textContent = checkbox.checked ? 'Completed' : 'Pending';
  });

  mutationObserverEl.addEventListener('mutation-observer-change', evt => {
    console.log('mutation-observer-change', evt.detail.mutations);
  });
</script>

Child node changes

Add or remove tasks from the list to observe changes to its child nodes.

  • Review pull request
  • Update documentation
Last mutation No mutations observed yet.
Code sample 
<button type="button" id="addButton">Add task</button>
<button type="button" id="removeButton">Remove last task</button>

<mutation-observer child-list>
  <ul id="taskList">
    <li>Review pull request</li>
    <li>Update documentation</li>
  </ul>
</mutation-observer>

<script>
  const mutationObserverEl = document.querySelector('mutation-observer');
  const addButton = document.getElementById('addButton');
  const removeButton = document.getElementById('removeButton');
  const taskList = document.getElementById('taskList');
  let count = taskList.children.length;

  addButton.addEventListener('click', () => {
    const task = document.createElement('li');
    task.textContent = `Task ${++count}`;
    taskList.appendChild(task);
  });

  removeButton.addEventListener('click', () => {
    const lastTask = taskList.lastElementChild;

    if (lastTask) {
      lastTask.remove();
    }
  });

  mutationObserverEl.addEventListener('mutation-observer-change', evt => {
    console.log('mutation-observer-change', evt.detail.mutations);
  });
</script>

Character data changes

Edit the task name to observe changes to its text content, including the previous value.

Task preview: Review pull request
Last mutation No mutations observed yet.
Code sample 
<label for="taskNameInput">Task name:</label>
<input type="text" id="taskNameInput" value="Review pull request">

<mutation-observer char-data char-data-old-value>
  <p>Task preview: <span id="taskLabel">Review pull request</span></p>
</mutation-observer>

<script>
  const mutationObserverEl = document.querySelector('mutation-observer');
  const input = document.getElementById('taskNameInput');
  const taskLabel = document.getElementById('taskLabel');

  input.addEventListener('input', () => {
    taskLabel.firstChild.data = input.value;
  });

  mutationObserverEl.addEventListener('mutation-observer-change', evt => {
    console.log('mutation-observer-change', evt.detail.mutations);
  });
</script>
